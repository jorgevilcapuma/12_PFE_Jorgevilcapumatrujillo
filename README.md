# 12_PFE_Jorgevilcapumatrujillo

Repositorio de prácticas del curso — **Vilcapuma Trujillo, Jorge Luis** (Estudiante 12).

Cada carpeta corresponde a una sesión y contiene un proyecto independiente en **Angular 19**.

| Sesión | Proyecto | Tema |
|---|---|---|
| S01 | [S01-biblioteca](S01-biblioteca/) | Sistema de biblioteca |
| S02 | [S02-RP-PerfilProfesional](S02-RP-PerfilProfesional/) | Perfil profesional |
| S03 | [S03_RP_GestionPedidos](S03_RP_GestionPedidos/) | Gestión de pedidos |
| S04 | [S04_RP_catalogopeliculas](S04_RP_catalogopeliculas/) | Catálogo de películas |
| S05 | [S05_RP_gestorpeliculas](S05_RP_gestorpeliculas/) | Gestor de películas |
| S06 | [S06_RP_BibliotecaDigital](S06_RP_BibliotecaDigital/) | Biblioteca digital |
| S07 | [S07_RP_catalogoproductos](S07_RP_catalogoproductos/) | Catálogo de productos |
| S08 | [S08_RP_inscripciontalleres](S08_RP_inscripciontalleres/) | Inscripción a talleres (Template Driven Forms) |
| S09 | [S09_RP_controlequipos](S09_RP_controlequipos/) | Control de equipos (Reactive Forms) |
| S10 | [S10_RP_validacionesequipos](S10_RP_validacionesequipos/) | Validaciones avanzadas de formularios |
| S11 | [S11_RP_tiendaproductos](S11_RP_tiendaproductos/) | Dashboard de tienda con Angular Routing |
| S12 | [S12_RP_logintienda](S12_RP_logintienda/) | Autenticación y Login con AuthService y Guards |

## Ejecutar un proyecto

```bash
cd <carpeta-del-proyecto>
npm install
ng serve
```

Abrir `http://localhost:4200/`.
